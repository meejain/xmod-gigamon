# Video / Lottie assets

Place the Deep Observability Pipeline Lottie animation here:

- **`dop.json`** – Used by the `lottie-animation` block (e.g. in the “Why Gigamon?” section).  
  Source: original site `/content/dam/website-assets/video/dop.json`.  
  Download from the source and add as `video/dop.json`, or set the **animation** link in the block’s table to another URL.

The block defaults to `${codeBasePath}/video/dop.json` if no “animation” row is provided in the block config.
